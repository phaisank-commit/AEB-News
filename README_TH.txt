AB NEWS - เว็บไซต์จุลสารออนไลน์ สาขาวิชาเศรษฐศาสตร์เกษตรและธุรกิจเกษตร
เวอร์ชัน 2.0: ปรับโฉมใหม่พร้อมโลโก้ AGRI และ AB จากไฟล์ที่ผู้ใช้ส่ง

ในชุดนี้ประกอบด้วย:
- index.html     หน้าเว็บหลัก
- styles.css     รูปแบบหน้าจอ คอมพิวเตอร์/มือถือ
- app.js         ระบบอ่านข่าว ค้นหา กรองหมวด และเปิดแต่ละฉบับ
- data.js        ข้อมูลข่าว 11 ฉบับ (87 ประเด็น)
- data.json      ข้อมูลข่าวรูปแบบ JSON สำหรับแก้ไข/ต่อยอด
- assets/agri.jpg   โลโก้ AGRI ครอบเฉพาะขอบว่างโดยคงรายละเอียดเดิม
- assets/ab.jpg     โลโก้ AB ครอบเฉพาะขอบว่างโดยคงรายละเอียดเดิม

1) เปิดดูทันที
หากต้องการเปิดไฟล์เดียวโดยไม่ต้องแตก ZIP ให้ใช้ไฟล์ AB_NEWS_2569_v2.html ที่แยกให้ดาวน์โหลดต่างหาก
ไฟล์นี้ฝังโลโก้และเนื้อหาทั้งหมดไว้ในไฟล์เดียว เปิดได้โดยไม่ต้องเชื่อมกับโฟลเดอร์รูป

2) นำขึ้น GitHub Pages
- แตกไฟล์ ZIP แล้วอัปโหลดไฟล์ index.html, styles.css, app.js, data.js และโฟลเดอร์ assets ขึ้น repository เดียวกัน
- เปิด Settings > Pages > Deploy from a branch > เลือก main / (root) > Save
- เมื่อเผยแพร่แล้ว เปิด URL จาก GitHub Pages ที่ระบบแจ้ง
- สามารถนำ URL ไปวางบน Google Sites หรือเพจ Facebook ของหลักสูตรได้

3) เพิ่มข่าวครั้งต่อไป
แก้ข้อมูลใน data.js (หรือจัดทำจาก data.json) โดยใช้โครงสร้างเดิมและเพิ่ม issue ใหม่
ควรทวนสอบสถานะงานและข้อมูลก่อนเผยแพร่

หมายเหตุ:
- ยังไม่ได้อัปโหลดขึ้นเว็บไซต์สาธารณะ
- ใช้ภาพโลโก้ต้นฉบับที่ส่งมา ครอบพื้นที่ขาวรอบภาพเพื่อการแสดงผลที่ชัดเจน
- ไม่เผยแพร่ต้นฉบับการประชุมหรือข้อมูลส่วนบุคคลที่ไม่เหมาะสมต่อสาธารณะ
